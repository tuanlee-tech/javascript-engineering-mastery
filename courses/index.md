# Khoá học

>Lộ trình **JavaScript Engineering Mastery** được chia thành **16 Stage** theo 4 Tầng năng lực. Chọn stage để bắt đầu hành trình của bạn.



## TẦNG I — JAVASCRIPT CORE

*Thiết lập mental model chính xác về ngôn ngữ và máy ảo trước khi tiếp cận bất kỳ framework nào.*

| Stage | Tên | Dự án |
|---|---|---|
| [Stage 0](/stages/00-javascript-language-foundation/) | Language Foundation | P0: CLI Data Processor |
| [Stage 1](/stages/01-javascript-execution-model/) | JavaScript Execution Model | P1: Mini Module System |
| [Stage 2](/stages/02-object-model/) | Object Model & Advanced JS | P2: Mini Object Framework |
| [Stage 3](/stages/03-async-concurrency/) | Asynchronous JS & Concurrency | P3: Production Search Engine |


## TẦNG II — WEB PLATFORM

*Đưa JavaScript vào môi trường trình duyệt thực tế, kết nối mạng và kiểm soát bộ công cụ hiện đại.*

| Stage | Tên | Dự án |
|---|---|---|
| [Stage 4](/stages/04-browser-runtime/) | Browser Runtime & Web Platform | P4: High-performance Browser App |
| [Stage 5](/stages/05-network/) | Network & Web Platform | P5: Network-aware Application |
| [Stage 6](/stages/06-typescript/) | TypeScript Engineering | P6: Typed Domain Library |
| [Stage 7](/stages/07-toolchain/) | Toolchain & JavaScript Ecosystem | P7: Build System from Zero |


## TẦNG III — FRONTEND ENGINEERING

*Làm chủ framework UI, xây dựng ứng dụng quy mô lớn và chạy ổn định trong môi trường người dùng thực tế.*

| Stage | Tên | Dự án |

| [Stage 11](/stages/11-performance-memory-security/) | Performance, Memory & Security | P11: Performance & Incident Lab |



## TẦNG IV — SYSTEM & LEADERSHIP
